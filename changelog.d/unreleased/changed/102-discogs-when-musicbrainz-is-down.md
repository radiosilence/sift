- **Discogs stands in for an unavailable MusicBrainz.** When the MusicBrainz part of an import fails transiently after its retries, Discogs is searched in its place: a strong match is applied and a weak one goes to review with its candidates, so an outage on one service no longer holds back an album the other knows. The import is put off only when Discogs is unavailable too or has nothing, or when the files name their MusicBrainz release. `Outcome` carries `musicbrainz_unavailable` with the reason, a breaking change for code that builds or matches it exhaustively.
