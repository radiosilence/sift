# sift

Music tagger and library organiser, published to crates.io as `sift-music`. koan and slsk-mcp depend on the library.

## Git

- Work in PRs; never push to main. PRs are squashed; merge main into a branch rather than rebasing.
- Never push tags or run `cargo publish`. CI tags and publishes when a release PR merges.
- Commits are signed.

## Changelog

`CHANGELOG.md` is generated by `scripts/changelog.py` and never edited by hand. Every change adds one fragment under `changelog.d/unreleased/<section>/`, named `<pr>-<slug>.md` and holding one `- **Lead.** Detail.` entry; to correct a note, edit its fragment. `just changelog --stdout` previews the result. The format is in `changelog.d/README.md`.

## Releasing

`just release patch|minor|major` (or an exact `X.Y.Z`) branches from main, bumps `Cargo.toml`, `Cargo.lock` and the README's dependency line, turns the unreleased fragments into the version and opens the release PR. Merging it is the release: CI publishes the crate, then the GitHub release with the binaries and the changelog section as notes, then the Homebrew formula. A push releases only when it changes the version; `gh workflow run ci.yml` on main retries a release that failed part way.
